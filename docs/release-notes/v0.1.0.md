# OneSource for Claude Code — v0.1.0

**Released:** <date>

OneSource brings ledger-based identity resolution to the coding agent you already use. Every
person and company resolves to one stable ID in a verified identity ledger of 75M+ companies and
people, which a data co-operative keeps growing. Every match comes with its evidence. From there,
your agent can fill in missing details, find the people who matter inside an account, build
prospect lists from your ICP, and check a mailbox before sending. You see what each step costs.

## What you can do

| Ask for | Tool | What you get back |
| --- | --- | --- |
| "Who is this?" | `onesource_resolve` | One stable OneSource ID for a work email, LinkedIn URL, or name and company, with what it matched on and how confident it is. Weak evidence and conflicts are flagged, never guessed. |
| "Fill in the gaps" | `onesource_enrich` | Missing fields such as title, company and work email, each with its source. Up to 100 contacts per call. |
| "Who runs marketing at Tallpine Software?" | `onesource_find` | People inside a known company, filtered by role and seniority. |
| "Find me more accounts like these" | `onesource_discover` | New accounts and contacts that match your industry, country, size, revenue and role filters. |
| "Is this mailbox safe to send to?" | `onesource_validate` | A verdict for each address: valid, invalid, catch-all, risky or unknown. Up to 1,000 per call. |

## What's in the plugin

- **Three skills** that teach the agent which tool to use when, what each verdict means, and how
  credits work: `onesource`, `who-matters` and `onesource-credits`.
- **A lead-qualification agent.** Hand it a list of leads or a CSV and a credit budget. It checks,
  enriches and fills out the buying group for each account, stops before going over budget, and
  returns a clean list grouped by account.
- **A usage log and `/onesource-usage`.** Each call writes one line to `~/.onesource/usage.jsonl`
  (tool, outcome, credits; never names, emails or other inputs). `/onesource-usage` shows credits
  per tool and your last 20 calls.

## Get started

```bash
claude plugin marketplace add <github-org>/onesource-plugin
claude plugin install onesource@icustomer-onesource
```

Restart Claude Code, run `/mcp`, choose `plugin:onesource:onesource` and pick **Authenticate**.
Sign in with your iCustomer account in the browser window that opens. Then try:

> Check these three emails and tell me which are safe to send to.

> Who runs marketing at these four accounts? Up to 3 people each, 30 credits max.

> Work through leads.csv with a 100-credit budget and give me a clean list by account.

**For scripts and CI**, use an API key instead of signing in: put it in `~/.onesource/api-key` and
the plugin sends it for you. Never commit a key to a repository.

**Other agents.** The tools work in any agent that can connect to a remote MCP server, and the
skills work in any agent that reads `SKILL.md` files. Setup steps for Codex, Hermes Agent and Pi
are in the README. So far we have tested only Claude Code end to end.

## Credits

Every answer shows two numbers: the most the call could cost (never above the `max_credits` you
set) and what it actually cost. The skills make the agent tell you both and ask before spending
beyond the budget you agreed on.

| Tool | Cost |
| --- | --- |
| Validate | 1 credit per valid, catch-all or risky address. Invalid and unknown are free. |
| Resolve | Free |
| Enrich | 1 credit per person or company lookup that filled a field; 2 for a work email |
| Find | 1 credit per person returned |
| Discover | 1 credit per contact returned |

You are charged only for results delivered. Rejected input, no match and errors on our side
cost nothing.

## Privacy

- **B2B only.** OneSource accepts work emails, LinkedIn profile URLs, names with a company, and
  company domains. It refuses personal emails, phone numbers and device IDs.
- **Bad input is stopped before it costs anything.** Test addresses, placeholder names and
  disposable domains are rejected before any lookup runs.
- **The local usage log holds no personal data.** The file is readable only by you, and you can
  delete it at any time.
